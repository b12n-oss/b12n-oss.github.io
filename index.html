Burin's Open Source Software

Where Burin Choomnuan publishes open source. Mostly Clojure and ClojureScript, with a run of Jolt work alongside it. Libraries and tools built for real use first, then written up properly.

b12n is a numeronym for burinchoomnuan: the first letter, the twelve in between, then the last. The same trick as i18n and k8s.

Projects

mcp-tkx

Clojure and ClojureScript library for building Model Context Protocol clients and servers. Five protocol revisions, dual-era sessions, and it runs on the JVM, Node and Babashka.

Public

raylib-jnk

212 of raylib's 217 official examples ported to jank, a native Clojure dialect compiled to native code via C++/LLVM, calling raylib directly through jank's C++ interop.

Public

raygui-jnk

24 raygui examples in jank, with raygui built as an ordinary jank package alongside raylib-jnk's C++/LLVM interop.

Public

raylib-clj

113 raylib examples in JVM Clojure, calling libraylib directly over coffi and JDK 22+'s Panama Foreign Function & Memory API. No wrapper library, no codegen.

Public

lambda-mvp-jlt

A shareable AWS Lambda custom runtime in Jolt (native Clojure on Chez Scheme), with a jolt bench tool for reproducing a cold-vs-warm boot-time comparison against your own AWS account.

Public

lambda-mvp-jnk

The same custom-runtime MVP in jank, native Clojure compiled to native code via C++/Clang/LLVM, deployed as a container image, with a bb bench tool for the same cold-vs-warm comparison.

Public

lambda-mvp-cljs

The third sibling: an AWS Lambda demo handler in ClojureScript on AWS's managed nodejs24.x runtime, completing a real cold/warm boot-time comparison across all three languages.

Public

lambda-mvp-rst

AWS Lambda custom runtime in Jolt (native Clojure on Chez Scheme), whose handler builds its JSON response with real Rust via jolt-diplomat, a Diplomat-based FFI bridge, instead of hand-assembling a string. Verified end to end against real Lambda infrastructure.

Public
